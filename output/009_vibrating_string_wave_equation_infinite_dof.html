Overview for the Curious

A guitar string seems simple, but it holds a deep secret of physics and mathematics. When you pluck it, it vibrates in a complex shape. However, this complex shape is not fundamental. It is actually the sum of many simple, "pure" vibrations called **harmonics** or **normal modes**. The first harmonic is the whole string vibrating up and down. The second is the string vibrating in two sections, and so on. The magic, discovered by Joseph Fourier, is that *any* possible shape or vibration of the string can be perfectly described by adding up the right amounts of these simple harmonic waves. This is **Fourier analysis**. This simulation lets you "pluck" a virtual string to create any shape you like, and then it instantly shows you the "recipe" of pure harmonics that combine to create the sound you would hear.
